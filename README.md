Employee Leave Management API
A production-style Employee Leave Management REST API built using ASP.NET Core 8, Entity Framework Core, SQL Server, JWT Authentication, Swagger/OpenAPI, Logging, and Global Exception Handling.

Features
✅ JWT Authentication & Authorization
✅ Employee Management
✅ Leave Request Management
✅ Manager Leave Approval Workflow
✅ SQL Server & Entity Framework Core
✅ Swagger/OpenAPI Documentation
✅ Structured Logging
✅ Global Exception Handling
✅ Clean Layered Architecture
✅ Azure Deployment Ready
